\noindent\textbf{Welcome, designers! Are you ready to start creating your characters?} \\
To make it easier for programmers to understand and know exactly which assets to integrate without sorting through unorganized files, please follow these guidelines when uploading your work to GitHub:

\begin{itemize}[leftmargin=*, nosep]
    \item \textbf{A. Folder Structure \& Status Tracking}
    \begin{itemize}
        \item Create a folder in the CHARACTERS directory named after your producer name.
        \item Inside it, add a file named \texttt{00\_CURRENT}. Update \texttt{00\_CURRENT} every time you work on something so that programmers and the manager can track your progress. Simply state what you are working on, which file it is in, and if you have finalized anything that should be verified this week.
        \item Inside your producer folder, add a separate subfolder for each character. Use the character's name as the folder name.
        \item Use the following naming suffixes to indicate the character's status:
        \begin{itemize}
            \item In-Progress: Append \texttt{\_DEMO} to the folder name (e.g., \texttt{CharacterName\_DEMO}).
            \item Ready for Review: Append \texttt{\_UNVERIFIED} (e.g., \texttt{CharacterName\_UNVERIFIED}).
            \item Approved: Once approved, the manager will rename the folder to \texttt{0\_[CHARACTER NAME]}.
        \end{itemize}
    \end{itemize}
    \vspace{0.2cm}
    \item \textbf{B. Required Character Folder Contents:} Inside each character's folder, you must create the following items:
    \begin{enumerate}
        \item A text file named \texttt{description.txt} detailing: Origin, general backstory, important gameplay mechanics, unlock conditions, and any other relevant details.
        \item A background image [screenshot] used when viewing the character in the Collection tab.
        \item All chibi states [screenshot] of the character: normally around 5 states (or 4 if immune to tiredness/sickness with duplicates).
        \item A folder containing all source PNG assets from the drawing application or browser tool you used.
        \item \textbf{Scenario Path} (Only required if the character is not unlocked at the start of the game):
        \begin{itemize}
            \item Talk to the manager for more information.
            \item Keep scenario paths concise unless the character has extensive lore. Maximum 7 steps: Easy ($\sim$3 steps), Medium ($\sim$5 steps), Hard ($\sim$7 steps).
            \item \textit{Scenario Flow Format:} SCENARIO START: Story 1 (no item required) $\rightarrow$ Story 2 (Requires YES/NO or specific item) $\rightarrow$ Story 3 \dots $\rightarrow$ Story 7 (Unlock the character).
        \end{itemize}
    \end{enumerate}
    \vspace{0.2cm}
    \item \textbf{References \& Examples:}
    \begin{itemize}
        \item Please read \texttt{60SECONDS2.0/CHARACTERS/00\_HOW TO MANAGE YOUR FILES IN CHARACTERS/ATTENTION.txt} to understand what to draw and write for characters.
        \item Example folder: \texttt{60SECONDS2.0/CHARACTERS/MOTHER/VALERIE\_UNVERIFIED/} (Warning: this is for a high difficulty character. Most characters need fewer skills, interactions, and shorter scenarios).
    \end{itemize}
    \vspace{0.2cm}
    \item \textbf{THE MAP:} When sending a character to scavenge, we select a position on the map giving different items by region/rarity. The map must AT LEAST INCLUDE: water, sea, ice island, nature, jungle, forests, castles, ports, pirate caves, pirate islands, volcano, a few empires, royals the humans, underseas caves with siren empire, other skull abandoned undersea items, a volcano with a demonic castle. Add other elements and discuss continent/place names with managers after drawing the map.
\end{itemize}
