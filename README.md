# 60SECONDS2.0

An evolutionary successor to the classic atomic survival genre, focusing on narrative depth, neighborhood-scale survival, and modern technical integration.

## Project Overview

**60Seconds2.0** is a next-generation survival framework that expands on the core mechanics of the original atomic survival experience. This project shifts the focus toward a complex neighborhood-scale ecosystem, utilizing a modern tech stack to manage deep narrative branching and character evolution.

### Key Features
- **Dynamic Neighborhood Pool:** Move beyond a single family to a diverse cast of survivors with unique skills and compatibility traits.
- **Advanced Character Progression:** Characters evolve through "Maturation" and "Skill Mastery" arcs based on your choices.
- **Robust Tech Stack:** Built with **FastAPI** for core logic, **Supabase** for secure state synchronization, and **React** for a diegetic, interactive journal interface.
- **Survival-Centric Design:** A specialized focus on the survival phase, replacing 3D scavenging with a deep "Randomized Scavenge Pack" and high-stakes resource management.
