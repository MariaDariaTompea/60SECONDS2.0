\section*{Section 1: Comprehensive Task Definitions \& Deliverables}

\subsection*{1.1. User Interface (UI) \& Login Systems}
\begin{itemize}
    \item \textbf{Login/Signup System:} (Prog 1 + Prog 2) Development of the authentication portal. Prog 1 will implement the Supabase Auth connection (handling user sessions, passwords, and security). Prog 2 will design the diegetic UI—a login screen that looks like a 1950s "Civil Defense Authorization" form.
    \item \textbf{Intro Background \& Cinematic:} (Puputeve) Puputeve will create the very first visual the player sees. This includes a high-detail painting of the pre-war neighborhood, used as the backdrop for the main menu and the initial story transition.
    \item \textbf{The Interactive Journal:} (Ilayda + Prog 2) This is the core UI. It must dynamically display text from Maria-Daria's scenario pool. It includes "Interactive Stamps" (choices), a calendar tracker, and individual character health/sanity monitors.
\end{itemize}

\subsection*{1.2. World-Building \& Environmental Art}
\begin{itemize}
    \item \textbf{Neighborhood Map:} (VikiPéDia) Viki will design the layout of the 60Seconds neighborhood. This is a grid-based map with 10-15 interactive locations (Pharmacy, Grocery, Military Outpost). It requires distinct icons for "Explored," "Unexplored," and "Hostile" states.
    \item \textbf{Shelter Interior:} (VikiPéDia + Puputeve) A layered 2D environment. Viki will block out the structure (lineart), and Puputeve will handle the final textures and lighting. It must feature interactive "Hotspots" (e.g., clicking the Radio opens the broadcast menu).
    \item \textbf{Item Asset Library:} (Puputeve) Creation of 20+ individual item sprites, including food, water, tools (Axe, Radio, Medkit), and rare quest items.
\end{itemize}

\subsection*{1.3. Narrative \& Technical Logic}
\begin{itemize}
    \item \textbf{30 Branching Scenarios:} (Maria-Daria) Maria-Daria will write 30 scenarios, each containing a prompt, 2-3 choices, and a matrix of outcomes (e.g., "If you have the Axe, you gain soup; if not, you get sick"). These must be formatted as JSON for backend integration.
    \item \textbf{The Entropy Engine (RNG):} (Ilayda) Developing the logic that decides which scenarios trigger each day. It uses "Weighted Probability" based on the current state (e.g., if the party is starving, the probability of finding food increases).
    \item \textbf{Metabolic Decay System:} (Prog 1) Programming the hidden variables for Hunger, Thirst, Fatigue, and Sanity. These variables must tick forward every "Midnight" cycle based on the choices made in the Journal.
\end{itemize}

\subsection*{1.4. Polish \& Meta-Systems}
\begin{itemize}
    \item \textbf{Achievement System:} (Prog 1 + Maria-Daria) Implementation of 15+ unlocks (e.g., "Survivalist," "Mutant Parent"). Maria-Daria defines the triggers; Prog 1 implements the tracking logic.
    \item \textbf{Audio \& Sound FX Triggers:} (Prog 2) Setting up the "Hooks" for sound effects (e.g., a "paper rustle" sound when the journal page turns, or a "Geiger click" when the radio is on).
\end{itemize}
