\section*{First Assignment Sprint}
\textbf{Duration:} September 1, 2026 -- September 25, 2026

\subsection*{Programmer Responsibilities}

\subsubsection*{Login Page \& Authentication}
Develop the initial login interface featuring four primary functional pathways:
\begin{enumerate}
    \item \textbf{Login with Existent Key:} Users authenticate using a pre-purchased key generated by our secure database. \textit{(Note: A separate web portal for key purchasing will be developed in a future assignment.)} For immediate testing purposes, developers must input 10 hardcoded valid keys into the database to allow project members immediate access with credentials. The system must actively validate the entered key against the database.
    \item \textbf{Keep Me Logged In:} A selectable checkbox widget. If checked, the user bypasses the login screen on subsequent client launches. If left unchecked, credentials must be re-entered upon every launch.
    \item \textbf{Start Chronometered Trial:} Grants new users a 3-hour free trial upon installation. Once the internal timer expires, the game forcibly pauses and prompts: \textit{"You have used your free trial. To continue, please log in with a pre-purchased key and your credentials."}
    \item \textbf{Sign Up:} For new users without an account. Registration requires inputting a Username, Email, Password, and a valid Pre-purchased Key.
\end{enumerate}

\subsubsection*{Main Menu \& Difficulty Selection}
\begin{itemize}
    \item \textbf{Layout Construction:}
    \begin{itemize}
        \item \textbf{Left Sidebar (33\%-40\% width):} Display the game title (temporary placeholder: \textit{Revamp60Seconds}) along with standard navigation buttons: \textbf{Play}, \textbf{Character List}, \textbf{Account Settings}, and \textbf{Logout}.
        \item \textbf{Right Main Area (60\%-66\% width):} Implement a dynamic background video player that smoothly crossfades and loops between three pre-rendered images provided by the art team.
    \end{itemize}
    \item \textbf{Difficulty Selection (\textit{Play Button Flow}):} Pressing 'Play' replaces the main menu with difficulty options. Hovering over each difficulty dynamically updates a tooltip description:
    \begin{itemize}
        \item \textbf{ROBOT:} \textit{Tutorial covering the basics of the game for new players. All items and game mechanics are introduced.}
        \item \textbf{EASY:} \textit{Characters are less susceptible to sickness and fatigue. Food and helpful survivors are plentiful. We've hit the jackpot with scavenging luck.}
        \item \textbf{MEDIUM:} \textit{We were able to gather enough resources to survive initially, but the sea is vast. Finding new resources is uncertain, and people grow weaker by the day.}
        \item \textbf{HARD:} \textit{The sea is unforgiving as we struggle to survive on limited resources. Sickness and exhaustion are frequent companions.}
        \item \textbf{NIGHTMARE:} \textit{The curse of the sea shows no mercy; it seems to actively hunt us down. Do you dare take the challenge?}
    \end{itemize}
\end{itemize}

\subsubsection*{Character List \& Database Architecture}
\begin{itemize}
    \item \textbf{Character Roster UI:}
    \begin{itemize}
        \item Clicking 'Character List' transitions to a scrollable grid/list displaying character names and portraits.
        \item Initially, the first four characters (A, B, C, D) are unlocked; remaining unowned characters are greyed out and display a padlock icon.
        \item Clicking an unlocked character displays a detail popup with their lore and statistics.
        \item Clicking a locked character triggers a popup stating: \textit{"You must first own this character to check its story and lore."} Clicking anywhere outside the popup dismisses it.
    \end{itemize}
    \item \textbf{Character Database Schema:}
    \begin{itemize}
        \item \textbf{Base Attributes:} Name, Description.
        \item \textbf{Core Stats (Ranked A, B, C):} IQ (Initial 4: Rank C), Strength (Initial 4: Rank C), Sickness Resistance Rate (Initial 4: Rank C).
        \item \textbf{Dynamic Stats:} Sickness Ratio (Default: 0\%), Tiredness Rate (Default: 0\%), Sanity (Default: 100\%).
        \item \textbf{Image States:} Each character entry requires four distinct visual states in the database corresponding to conditions: Sane, Insane, Sick, Tired.
        \item \textbf{State Override Logic:} The active character portrait is determined by their most severe debuff. For example, if a character has 50\% sickness but 0\% sanity, the "Insane" portrait takes highest priority and is displayed globally.
    \end{itemize}
\end{itemize}

\subsection*{Artist Responsibilities}

\subsubsection*{Login Interface Aesthetics}
\begin{itemize}
    \item \textbf{Background Matte:} Design a highly detailed, thematic pirate map background. \textit{(Reference the \texttt{MAP.txt} document in the TASKS folder for specific element descriptions and structural requirements).}
    \item \textbf{UI Elements:} Design a clean, simple 'Login' button accented with subtle, thematic marine features (e.g., stylized tentacles along the border). The 'Sign-Up' bar and overall menu styling must maintain strict visual consistency with these login assets.
\end{itemize}

\subsubsection*{Main Page Looping Backgrounds}
Create three distinct, high-quality illustrations designed to crossfade and loop smoothly in the main menu background video:
\begin{enumerate}
    \item A naval ship viewed directly from the front at a 45-degree elevated angle.
    \item A lush tropical island scene featuring a siren partially concealed behind a tree, positioned alongside an ornate treasure chest.
    \item A 60-degree top-down perspective looking at a wooden occult table. The table must feature an open spellbook bearing a magical sign \textit{(Reference \texttt{OCCULT.txt} for design hints and rough sketches)}, an atmospheric skull, and other esoteric nautical artifacts.
\end{enumerate}

\subsubsection*{Difficulty Selection Icons}
Design simple, elegant iconography for the difficulty setting buttons. 
\begin{itemize}
    \item Standard buttons should incorporate small thematic symbols (e.g., a stylized anchor, a fish).
    \item The \textbf{NIGHTMARE} difficulty button must prominently feature a menacing demonic eye.
    \item Despite variations, all icons must look completely cohesive and clearly belong to the same UI asset bundle.
\end{itemize}
